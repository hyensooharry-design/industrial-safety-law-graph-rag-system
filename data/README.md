# Data

## Raw case sources

`raw_cases/` contains the broader public source-case collection used during case-scenario dataset construction.

The manuscript's final quantitative evaluation does **not** use every raw file in this directory as an independent evaluation case. The final manuscript evaluation contains 42 scenarios derived from 33 criminal precedents and 9 administrative adjudications.

Processed and reviewed evaluation artifacts are stored under `../evaluation/`.

## Legal source data

The legal knowledge graph is based on statutory information collected through the Korean national law information open API and represented as structured graph artifacts under `../knowledge_graph/`.
