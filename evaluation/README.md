# Evaluation Artifacts

This directory contains the public case-scenario evaluation workspace associated with the manuscript.

The manuscript's final evaluation uses **42 scenarios**: 33 criminal precedent-based scenarios and 9 administrative adjudication-based scenarios. The repository also retains broader intermediate artifacts produced during source-case inventory, extraction, legal-reference mapping, selector development, ablation, review, and validation.

Important distinction:

- **Manuscript-reported evaluation:** final 42-case set.
- **Repository workspace:** includes the broader intermediate artifacts used to construct and validate that final evaluation.

For the manuscript-facing metrics and interpretation, see `../docs/EVALUATION.md`.
